# مأموریت نجات — نسخهٔ پایتون

بازی آموزشی «مأموریت نجات» با موتور کامل پایتون و سرور FastAPI. دانش‌آموز با
قانون‌های «اگر … آنگاه …» مغز ربات نجات را طراحی می‌کند، اجرایش را روی تختهٔ
۱۲×۱۲ تماشا می‌کند و استراتژی‌اش را با عامل یادگیرنده (Q-Learning) مقایسه
می‌کند. همهٔ منطق بازی — تولید نقشه، دایکسترا، پاداش‌ها و یادگیری تقویتی —
در پایتون است؛ مرورگر فقط نمایش می‌دهد.

## نصب و اجرا

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

بعد مرورگر را باز کن: **http://localhost:8000**

رمز ادمین: **۱۲۳** — رمز مرحلهٔ بعد (باز کردن آزمایش بزرگ): **۱۳۸۴**
(از متغیرهای محیطی `ADMIN_CODE` و `STAGE_CODE` هم می‌شود عوضشان کرد.)

## ساختار پروژه

```
run.py                  اجرای سرور (uvicorn روی پورت 8000)
app/
  __init__.py
  config.py             مقدارهای پیش‌فرض، فیلدهای پارامتر، ۱۴ شرط، ۸ اقدام، ۷ استراتژی آماده
  engine.py             موتور بازی: mulberry32، genMap، دایکسترا، مشاهده، شرط‌ها، stepEnv
  rules.py              تمیز کردن و اعتبارسنجی قانون‌ها
  qlearning.py          عامل یادگیرنده: Q(λ) با λ=0.8، جدول ریز و درشت، checkpoint
  scenarios.py          ۶ سناریوی تغییر ناگهانی محیط
  store.py              ذخیره‌سازی سراسری روی سرور (data/*.json)
  server.py             سرور FastAPI و همهٔ endpointها
static/
  index.html            صفحهٔ فارسی راست‌به‌چپ
  style.css             سبک مدرن (روشن/تیره)
  app.js                فقط با API سرور حرف می‌زند؛ منطق بازی ندارد
tests/
  test_engine.py        تعیین‌پذیری نقشه، برداشتن و تحویل مصدوم
  test_qlearning.py     آموزش کوتاه و امتیاز عددی
  test_api.py           تنظیمات، قفل‌ها، شبیه‌سازی، استراتژی‌ها
data/                   تنظیمات و داده‌های سرور (در گیت نمی‌رود)
```

## خلاصهٔ API

| روش | مسیر | توضیح |
| --- | --- | --- |
| GET | `/api/meta` | شرط‌ها، اقدام‌ها، پیش‌فرض‌ها، سناریوها، پارامترها |
| GET / PUT | `/api/settings` | خواندن / تغییر تنظیمات سراسری (PUT با هدر `X-Admin-Code: 123`) |
| POST | `/api/settings/reset` | بازگشت تنظیمات به پیش‌فرض (ادمین) |
| POST | `/api/unlock` | باز کردن قفل مرحله (`1384`) یا ادمین (`123`) |
| POST | `/api/simulate` | اجرای یک استراتژی روی یک نقشه؛ قدم‌ها و لاگ تصمیم |
| POST | `/api/train` | آموزش عامل یادگیرنده؛ منحنی + امتیاز اعتبارسنجی |
| GET | `/api/train/status` | وضعیت آموزش و استراتژی مدل |
| POST | `/api/train/reset` | شروع دوبارهٔ آموزش از صفر |
| POST | `/api/compare` | مقایسهٔ انسانی و عامل روی نقشه‌های یکسان + دو ردّ قدم |
| POST | `/api/finetune` | یادگیری دوباره در محیط جدید، بعد مقایسه |
| GET / POST / DELETE | `/api/strategies` | استراتژی‌های ذخیره‌شده روی سرور |
| GET / POST / DELETE | `/api/admin-presets` | تنظیم‌های ذخیره‌شدهٔ ادمین (ادمین) |
| GET / PUT | `/api/scenarios` | سناریوهای تغییر محیط |
| POST | `/api/shock` | اعمال سناریوی تصادفی (یا با اندیس) |
| POST | `/api/restore-env` | بازگشت به محیط عادی |

## نکته‌های مهم

- تنظیمات سراسری روی سرور ذخیره می‌شوند (`data/settings.json`) و برای همهٔ
  کاربران اعمال می‌شوند — برخلاف نسخهٔ قدیمی که در مرورگر هر کاربر بود.
- آموزش عامل روی سرور انجام می‌شود و جدول یادگیری در `data/qmodel.json`
  ذخیره می‌شود تا بعد از راه‌اندازی دوبارهٔ سرور هم بماند.
- تست‌ها: `pytest -q`
